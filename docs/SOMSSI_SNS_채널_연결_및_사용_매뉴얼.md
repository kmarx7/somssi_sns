## 2. [방법 A] API 설정 없이 대시보드에서 5초 만에 연결하기 (가장 추천)

별도의 유료 프로그램이나 메타(Meta) 개발자 앱 심사 없이, 대시보드에 내장된 **원클릭 플랫폼 런처(Direct Launcher)**를 사용하는 방법입니다.

### 2.1 🧵 스레드 (Threads) 연결 및 게시 방법

스레드는 메타의 공식 웹 인텐트(`https://www.threads.net/intent/post?text=...`) 기능을 지원하여, 클립보드 붙여넣기조차 필요 없이 **입력창에 글이 미리 채워진 상태**로 열립니다.

1. 대시보드 좌측에서 오늘의 주제(요일별 추천 또는 실시간 RSS 뉴스)를 선택하고 **`4개 채널 초안 생성 (Generate)`** 버튼을 클릭합니다.
2. 중앙 상단 탭에서 **`🧵 Threads`** 탭을 클릭합니다.
3. 우측의 파란색 버튼 **`🚀 스레드 앱/웹 바로 열기 (본문 자동 입력)`**을 클릭합니다.
   - *(또는 우측 상단 **`검수 승인 & 배포(UTM 치환)`** 모달 안의 **`🧵 스레드 바로 올리기`** 버튼을 클릭해도 동일하게 작동합니다.)*
4. 브라우저 새 탭으로 스레드(`threads.net`)가 열리며, **방금 생성된 한·영 스레드 원고와 UTM 추적 링크가 입력창에 자동으로 들어가 있습니다.**
5. 내용을 확인한 뒤 스레드 화면의 **`게시(Post)`** 버튼만 누르면 업로드가 완료됩니다.

### 2.2 📝 네이버 블로그 (Naver Blog) 연결 및 게시 방법

네이버 블로그는 2020년 이후 외부 자동 글쓰기 API(XML-RPC)를 공식 종료했으며, 비공식 봇 프로그램을 사용할 경우 블로그 저품질(검색 누락) 페널티를 받을 수 있습니다. 따라서 대시보드는 **네이버 스마트에디터 ONE이 인식하는 Rich HTML 서식(`H1`, `H2`, 문단, 구분선, 영문 요약박스)을 클립보드에 심어주고 글쓰기 창을 바로 띄워주는 안전하고 빠른 방식**으로 연결되어 있습니다.

1. 중앙 상단 탭에서 **`📝 Naver Blog`** 탭을 클릭합니다.
2. **블로그 한/영 구성 모드** 3가지 중 원하는 스타일을 선택합니다.
   - **🇰🇷+🌐 국문 본문 + 하단 영문 요약 (추천)**: 네이버 한국어 검색 상위 노출(SEO)을 잡으면서 외국인 방문자에게 하단 영문 안내를 제공합니다.
   - **🇰🇷/🇺🇸 문단별 한·영 병기 (Bilingual)**: 한국어 문단 바로 아래에 영어 번역 문단이 세트로 배치됩니다.
   - **🇺🇸 100% 영문 전용 포스트**: 해외 검색엔진 및 글로벌 독자 전용 영문 포스트입니다.
3. 우측의 초록색 버튼 **`🟢 네이버 블로그 글쓰기 바로 열기 (서식 자동 복사)`**를 클릭합니다.
4. 자동으로 다음 두 가지가 동시에 실행됩니다:
   - 선택된 언어 모드의 **제목·소제목(H2)·본문·영문 요약·해시태그가 스마트에디터 서식 그대로 클립보드에 복사**됩니다.
   - 새 탭으로 **네이버 블로그 글쓰기 창(`https://blog.naver.com/GoBlogWrite.naver`)**이 열립니다.
5. 네이버 블로그 에디터 본문 영역을 마우스로 클릭한 뒤 **`Cmd + V` (Windows는 `Ctrl + V`)**를 누르면 소제목 크기와 줄바꿈이 깔끔하게 유지된 채 본문이 한 번에 입력됩니다.
6. **블로그 이미지 넣기**:
   - `📝 Naver Blog` 탭 하단의 **`🖼️ 네이버 블로그 섹션 배너 이미지 스튜디오 (1200×630 PNG)`**에서 **`전체 배너 일괄 다운로드 (4장)`**을 클릭합니다.
   - 다운로드된 `somssi_naver_blog_section_1.png ~ 4.png` 파일을 네이버 블로그 각 소제목 아래에 마우스로 끌어다 놓으면(Drag & Drop) 고품질 포스트가 완성됩니다.

### 2.3 📸 인스타그램 피드 (Instagram Feed) 연결 및 게시 방법

인스타그램 피드는 **4장의 정방형(`1080×1080`) 카드뉴스 이미지**와 **한·영 병기 캡션 + 해시태그 8개**가 한 세트로 구성됩니다.

1. 중앙 상단 탭에서 **`📸 Instagram Feed`** 탭을 클릭합니다.
2. 하단의 **`🎨 인스타그램 & 블로그 카드뉴스 이미지 스튜디오`**에서 원하는 배경 테마를 선택합니다.
   - `전통 한지 & 먹색 골드` / `고려청자 비색 & 우드` / `송도 한옥 야경 다크` / `오방색 비단 파스텔`
   - 직접 찍은 한옥이나 가야금 사진을 배경으로 넣고 싶다면 각 카드 아래의 **`배경 사진 넣기`** 버튼을 눌러 사진을 합성할 수 있습니다.
3. 우측 상단의 **`검수 승인 & 배포(UTM 치환)`** 버튼을 누른 뒤, **`📸 인스타 바로 올리기 (PNG 4장 저장 + 인스타 열기)`** 버튼을 클릭합니다.
4. 자동으로 다음 세 가지가 동시에 실행됩니다:
   - `somssi_ig_card_1.png` ~ `somssi_ig_card_4.png` (총 4장, 1080×1080 고해상도) 파일이 내 컴퓨터 다운로드 폴더에 저장됩니다.
   - UTM 예약/안내 링크가 치환된 **인스타그램 캡션 + 해시태그 8개**가 클립보드에 자동 복사됩니다.
   - 새 탭으로 **인스타그램 웹(`https://www.instagram.com/`)**이 열립니다.
5. 열린 인스타그램 화면 좌측 메뉴에서 **`+ 만들기(Create)` → `게시물`**을 누르고:
   - 방금 다운로드된 PNG 4장을 선택해 올립니다.
   - 문구 입력란에 **`Cmd + V` (붙여넣기)**를 누르고 **`공유하기`**를 누르면 게시가 완료됩니다.

### 2.4 🎬 릴스 & 틱톡 (Reels / TikTok) 연결 및 게시 방법

릴스와 틱톡은 짧은 세로형 영상(15초)에 들어갈 **0~3초 초반 후킹 문구(Hook)**, **장면별 화면 자막(On-screen Text)**, **오디오 가이드**, 그리고 **캡션 + 해시태그**를 제공합니다.

1. 중앙 상단 탭에서 **`🎬 Reels (15s)`** 탭을 확인하고, 필요 시 **`📋 대본+캡션 전체 복사`** 또는 **`📋 캡션+해시태그만 복사`**를 클릭합니다.
2. 우측 상단 **`검수 승인 & 배포(UTM 치환)`** 모달에서 **`🎬 릴스/Meta Suite 열기 (대본·캡션 복사)`**를 클릭합니다.
3. 대본과 캡션이 클립보드에 복사되며, 새 탭으로 **Meta Business Suite 통합 게시 도구(`https://business.facebook.com/latest/composer`)**가 열립니다.
4. 촬영/편집된 15초 영상을 업로드하고 캡션란에 **`Cmd + V`**를 붙여넣어 인스타그램 릴스와 페이스북 릴스에 동시에 게시하거나 원하는 날짜/시간으로 예약 게시할 수 있습니다.

## 3. [방법 B] Make.com 웹훅(Webhook)으로 스레드·인스타그램 완전 자동 게시 파이프라인 구축하기

매번 각 사이트 창을 열지 않고, 대시보드의 **`최종 승인 & 배포 실행`** 버튼 한 번으로 스레드와 인스타그램에 동시에 자동 업로드되도록 만들고 싶을 때 설정하는 방법입니다.

### 3.1 사전 준비 사항 (최초 1회, 약 5분 소요)

1. **인스타그램 프로페셔널(비즈니스/크리에이터) 계정 전환**
   - 메타(Meta) 공식 정책상 일반 개인 계정은 외부 자동 게시 API를 사용할 수 없으며, 무료로 전환 가능한 **프로페셔널 계정**만 허용됩니다.
   - 인스타그램 모바일 앱 실행 → `[프로필]` → 우측 상단 `[☰ 설정 및 활동]` → `[계정 유형 및 도구]` → **`[프로페셔널 계정으로 전환]`** 클릭 (`크리에이터` 또는 `비즈니스` 선택)
   - 본인(또는 브랜드)의 **Facebook 페이지**와 연결합니다.
2. **Make.com 무료 가입**
   - `https://www.make.com` 에 접속해 무료 계정으로 가입합니다 (월 1,000 Operations 무료 제공).

---

### 3.2 Step 1 — Make.com에서 웹훅(Webhook) 주소 만들고 대시보드에 저장하기

1. Make.com 로그인 후 우측 상단 **`+ Create a new scenario`** 버튼을 클릭합니다.
2. 화면 중앙의 커다란 보라색 **`+`** 원형 버튼을 클릭하고 검색창에 **`Webhooks`**를 입력합니다.
3. **`Webhooks` → `Custom webhook`**을 선택합니다.
4. **`Add`** 버튼을 누르고 이름을 `SOMSSI SNS Webhook`으로 입력한 뒤 **`Save`**를 누릅니다.
5. 생성된 웹훅 주소(예: `https://hook.eu2.make.com/abcd1234efgh5678...`) 옆의 **`Copy address to clipboard`**를 클릭합니다.
6. 우리 대시보드(`http://localhost:3400`)로 돌아와서 우측 상단 **`검수 승인 & 배포(UTM 치환)`** 버튼을 클릭합니다.
7. **[방법 B. Make.com 웹훅(Webhook) 자동화 파이프라인 연결]** 섹션의 입력칸에 방금 복사한 주소를 붙여넣고 **`💾 URL 저장`** 버튼을 누릅니다. *(한 번 저장해 두면 브라우저에 영구 기억됩니다.)*
8. Make.com 화면에서 `Redetermine data structure`가 돌아가고 있을 때, 대시보드 하단의 **`최종 승인 & 배포 실행`** 버튼을 한 번 눌러줍니다.
9. Make.com 화면에 **`Successfully determined`**라는 초록색 메시지가 뜨면 데이터 구조 연결이 완료된 것입니다!

---

### 3.3 Step 2 — 스레드(Threads) 자동 게시 모듈 연결하기

1. Make.com에서 방금 만든 `Webhooks` 동그라미 우측의 **`+` (Add another module)** 버튼을 클릭합니다.
2. 검색창에 **`Threads`**를 검색하여 **`Threads` → `Create a Thread`**(또는 `Create a Post`)를 선택합니다.
3. `Connection` 옆의 **`Add`** 버튼을 눌러 본인 스레드(인스타그램) 계정으로 로그인 및 권한 승인을 완료합니다.
4. 입력 필드를 아래 표와 같이 매핑(클릭해서 선택)하고 **`OK`**를 누릅니다.

| Make.com 필드명 | 대시보드 웹훅에서 끌어다 놓을 변수 | 설명 |
| :--- | :--- | :--- |
| **Text** | `publishedPayload` → `threads` → **`text`** | UTM 링크가 치환된 스레드 본문 전체 (300자 이내) |

---

### 3.4 Step 3 — 인스타그램 비즈니스(Instagram for Business) 자동 게시 모듈 연결하기

1. 앞선 모듈 우측의 **`+` (Add another module)** 버튼을 클릭합니다.
2. **`Instagram for Business`**를 검색하여 선택합니다.
   - 단일 사진 게시: **`Create a Photo Post`**
   - 여러 장(캐러셀) 게시: **`Create a Carousel Post`**
3. `Connection` 옆의 **`Add`** 버튼을 눌러 페이스북/인스타그램 비즈니스 계정을 연동합니다.
4. 입력 필드를 아래 표와 같이 매핑하고 **`OK`**를 누릅니다.

| Make.com 필드명 | 대시보드 웹훅에서 끌어다 놓을 변수 | 설명 |
| :--- | :--- | :--- |
| **Caption** | `publishedPayload` → `instagram_feed` → **`caption`** 과 **`hashtags`** | 한·영 캡션 본문 및 해시태그 배열 (`join(hashtags; " ")` 함수로 공백 연결 가능) |
| **Photo URL** | 공개 이미지 URL (또는 클라우드 드라이브/호스팅 이미지 URL) | 메타 API 특성상 이미지는 공개 URL 형태이거나 대시보드에서 다운로드한 PNG를 사용합니다. |

---

### 3.5 Step 4 — 시나리오 켜기(ON) 및 원클릭 배포 실행

1. Make.com 좌측 하단의 **`Scheduling`** 스위치를 **`ON` (`Immediately as data arrives`)**으로 켭니다.
2. 저장 아이콘(💾)을 눌러 시나리오를 저장합니다.
3. 이제부터 대시보드에서 초안을 검토한 뒤 **`검수 승인 & 배포(UTM 치환)` → `최종 승인 & 배포 실행`** 버튼을 누를 때마다 Make.com 시나리오가 즉시 작동하여 연결된 SNS 채널로 자동 발행됩니다.

### 4.2 특정 채널만 마음에 들게 고치는 `부분 수정 (Revise)` 기능

생성된 4개 채널 중 **특정 채널 1개만 문구를 다듬고 싶을 때** 전체를 다시 생성할 필요가 없습니다.

1. 좌측 하단의 **`부분 수정 (Revise 모드)`** 패널로 이동합니다.
2. **`수정 대상 채널 (단일 선택)`**에서 고치고 싶은 채널(`threads`, `instagram_feed`, `naver_blog`, `reels` 중 하나)을 선택합니다.
3. **`수정 지시어`** 입력칸에 원하는 요청사항을 적습니다.
   - 예시 1: *"외국인 친구에게 말하듯 조금 더 친근하고 따뜻한 톤으로 바꿔줘"*
   - 예시 2: *"송도 센트럴파크 야경 산책 코스를 한 줄 더 강조해줘"*
4. **`선택 채널만 부분 수정`** 버튼을 누르면 **나머지 3개 채널의 원고는 100% 그대로 보존**되고 선택한 채널만 즉시 수정됩니다.
   - *(만약 "가격을 50% 할인한다고 적어줘" 또는 "지금 바로 결제 가능하다고 적어줘"처럼 사실관계/상품 판매 예정 상태와 충돌하는 지시를 입력하면, AI가 허위 사실을 적지 않고 안전하게 방어한 뒤 상단 노란색 `검수자 알림(reviewer_notes)` 배너에 사유를 보고합니다.)*

### 4.3 API 과금 없는 AI 구독 CLI 연결 방법 (선택 사항)

유료 OpenAI API 키 결제 없이, 이미 구독 중인 **Claude Pro/Max, ChatGPT Plus/Pro, Gemini**를 연결해 초안을 생성할 수 있습니다.

1. 상단 바 우측의 **`🔌 CLI 연결 상태`** 버튼을 클릭합니다.
2. 터미널 명령어 옆의 **`복사`** 버튼을 눌러 터미널(Terminal.app)에서 한 번만 로그인합니다:
   - **Claude 구독자**: `claude login`
   - **ChatGPT Plus/Pro 구독자**: `codex login`
   - **Google Gemini 사용자**: `gemini` 실행 후 `Login with Google` 선택 (무료)
3. 로그인 후 모달 하단의 **`🔄 설치 및 연결 상태 다시 확인`** 버튼을 누르면 상단 엔진 선택창에서 해당 AI CLI를 선택하여 초안을 생성할 수 있습니다.
4. 터미널 설치가 번거로울 때는 엔진 선택창에서 **`🌐 웹 구독 복붙 브리지 (ChatGPT / Claude / Gemini 웹)`**를 선택하면, 평소에 쓰시는 웹 채팅창에 프롬프트를 복사·붙여넣기하여 동일하게 사용할 수 있습니다.
